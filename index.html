Como Configurar
  1. Crie uma Google Sheets e copie o ID da URL
  2. Acesse script.google.com → Novo projeto
  3. Cole o Code.gs e altere o SHEET_ID
  4. Execute inicializarPlanilha()
  5. Implantar → Web App → acesso: Qualquer pessoa
  6. Cole a URL acima e teste a conexão
  7. Publique o index.html no GitHub Pages
