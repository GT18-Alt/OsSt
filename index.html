📖 Como Configurar

  1. Acesse script.google.com e crie um novo projeto
  2. Cole o conteúdo do arquivo Code.gs no editor
  3. Altere a variável SHEET_ID para o ID da sua planilha
  4. Clique em Implantar → Nova implantação
  5. Selecione Aplicativo da Web, defina acesso como Qualquer pessoa
  6. Copie a URL gerada e cole no campo acima
  7. Hospede o index.html no GitHub Pages
